## 機能

- 🗺 **国土地理院地図** + 住所入力で飛行場所を指定・ルート描画
- 🧭 **住所検索候補を最大5件表示**し、飛行場所を本人が確認して選択
- 🔍 **DID（2020年版）・空港距離の簡易判定**（空港の法定区域は公式地図で最終確認）
- 🌤 **気象情報取得**（Open-Meteo・風速警告付き）
- 📋 **カテゴリー自動判定**（Ⅰ / ⅡB / ⅡA / Ⅲ / 禁止）
- 📮 **申請先一覧の自動生成**（Google検索リンク付き）
- 📝 **DIPS2.0申請書下書き**（コピペ用）
- ✅ **飛行前チェックリスト**（20項目）
- 📓 **飛行記録（様式１）** — 航空法施行規則第236条の84準拠・CSV/Excel出力・同一機体の「製造後の総飛行時間」を直近記録から自動入力
- 🔧 **機体点検・保険満了日リマインダー**（任意入力・自己管理用。期限が近い/過ぎている場合にチェック画面へ表示）
- 🔄 **起動時バージョン・法令確認日チェック**（GitHubの状態ファイルと比較）
- 💾 **全データのエクスポート/インポート**（JSONバックアップ）
- 🪪 **パイロット情報の保存**（次回自動入力）

## 起動・アップデート方法

| 操作 | Windows | macOS |
|------|---------|-------|
| 起動 | `01_アプリ起動.bat` をダブルクリック | `01_アプリ起動.command` を右クリック→開く（初回）|
| 変更を保存（GitHubへアップロード） | `02_GitHubへアップロード.bat` | `02_GitHubへアップロード.command` |
| 最新版を取得（GitHubからダウンロード） | `03_GitHubからダウンロード.bat` | `03_GitHubからダウンロード.command` |

※ `drone_checker.html` は直接ブラウザで開けます。ただし、同じフォルダ構成の `vendor/` も必要です。
※ Macで `.command` を初めて実行する場合は、フォルダで一度だけ `chmod +x *.command` を実行してください（Gitで取得した場合は実行権限が記録済みのため不要です）。

├── vendor/                                   # 固定版のLeaflet・JSZipとライセンス

> **注意**: Leaflet・JSZipは固定版を`vendor/`へ同梱しています。Excel・JSON出力は外部CDNへ接続せず利用できます。地図・住所検索・DID・天気・法令確認は外部データを取得するため、オフラインでは利用できません。

## セキュリティ

- **外部通信**: 国土地理院API・地理院地図タイル・OpenStreetMapタイル・Open-Meteo・GitHub
- **個人・運航情報**: ブラウザの `localStorage` のみに保存し、地図・天気等の外部通信へ含めない
- **XSS対策**: ユーザー入力はすべてエスケープ処理済み
- **外部ライブラリ**: Leaflet 1.9.4・JSZip 3.10.1をアプリ内へ同梱し、第三者CDNのJavaScriptを実行しない。未使用だったXLSXは配布対象から削除
- **個人情報**: DIPS ID・機体番号・保険番号も個人・運航情報です。不要な完全番号は保存せず、自分の端末だけで使用してください

## 個人情報の取り扱い

入力したパイロット情報・飛行記録はすべてブラウザのlocalStorageに保存されます。
アプリはこれらの個人・運航情報を外部へ送信しません。ただし、次の機能は必要な情報を外部サービスへ送ります。

| 操作 | 送信される情報 | 送信先 |
|---|---|---|
| 住所検索 | 入力した住所・地名 | 国土地理院 |
| 地図・DID判定 | 表示範囲、選択した座標 | 国土地理院、OpenStreetMap |
| 天気取得 | 選択した座標、飛行予定日 | Open-Meteo |
| 起動時確認 | アプリのバージョン・法令状態の取得要求（個人・運航情報は含まない） | AWS版は同じCloudFront配信、ローカル版はGitHub |

外部サービスには通常、通信元IPアドレスやブラウザ情報も伝わります。また：

- ブラウザの開発ツール（F12）から内容は確認可能です
- 同じページで動くJavaScriptからもlocalStorageを読み取れるため、共用PCでは保存しないでください
- ブラウザのデータ削除で消えます → **定期的にJSONエクスポートでバックアップ**を推奨
- JSONインポートは2MB上限・データ型・最大件数を検査します

## 対応法令

- 航空法・施行規則第236条の84（飛行日誌）
- 小型無人機等飛行禁止法（2026年7月14日改正施行。対象施設周辺おおむね1,000m）
- 無人航空機の飛行日誌の取扱要領（令和4年12月制定）
- 小型無人機等飛行禁止法 / 道路交通法 / 河川法 / 都市公園法 / 農薬取締法

対象空港の赤い1km円は空港代表点からの**簡易目安**で、法定区域の正確な境界ではありません。
飛行前に警察庁の指定資料・地理院地図・DIPS2.0を必ず確認してください。

`.github/workflows/law-review.yml` は週1回、`law_status.json` の確認日が35日以上古くないか、
公式ページの基準文言が変わっていないかを読み取り専用で検査します。法令内容を自動判断・自動更新はしません。

## AWS Phase 1

AWS版は、非公開S3へ必要な12ファイルだけを置き、CloudFrontのHTTPS URLから配信する設計です。EC2等の常時起動サーバーは使いません。Windowsローカル版はそのまま残り、AWSへパイロット情報・飛行記録を保存しません。

AWSはまだ作成していません。実際に配置するときは [`deploy/aws/README.md`](deploy/aws/README.md) から読み、ユーザー本人がAWS画面を操作します。`deploy/aws/scripts/01_配布フォルダ作成.bat` はローカルの配布物を検査するだけで、AWSへの送信や課金は発生しません。
