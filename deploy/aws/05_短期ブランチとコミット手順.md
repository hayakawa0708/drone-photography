# drone 短期ブランチとコミット手順

更新日: 2026-08-13

短期branchはフォルダコピーではなく、安全な`main`から一時的に分ける作業レーンです。commitはPC内の履歴保存、pushはGitHubへの送信、deployはAWSへの公開です。commit・pushだけではAWS料金は発生しません。

```powershell
cd C:\Users\haya0\Documents\drone
git status --short
git switch -c feature/drone-aws-ready
git add -- .gitignore CHANGELOG.md README.md deploy.py drone_checker.html law_status.json .github tests vendor deploy
git diff --cached --name-only
git diff --cached
& 'C:\Users\haya0\Documents\stock\venv\Scripts\python.exe' -m unittest discover -s tests -v
git commit -m "droneのAWS公開前安全性を改善"
git push -u origin feature/drone-aws-ready
```

`.claude/`、`.aws-build/`、ログ、個人データ、AWS認証情報は追加しません。`git add .`と`--no-verify`は使いません。commit・pushはユーザーの明示依頼後に実行します。
