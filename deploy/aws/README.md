# drone AWS Phase 1

更新日: 2026-08-13  
現在地: **ローカル準備中 / AWS未作成**

droneはサーバー処理のない静的Webアプリです。Phase 1では、東京リージョンの非公開S3へ実行ファイルだけを置き、CloudFrontのHTTPS URLから公開します。

## Phase 1の構成

```text
利用者のブラウザ
       │ HTTPS
       ▼
CloudFront（公開入口・セキュリティヘッダー）
       │ 署名付き読取
       ▼
S3（東京・直接公開しない）
```

- S3: HTML、法令状態JSON、同梱ライブラリを保存する非公開ファイル置き場
- CloudFront: HTTPSで配信する公開入口。サーバーの常時稼働料金はない
- OAC: CloudFrontだけにS3の読取を許可する仕組み
- CloudFormation: 上記設定を同じ内容で作る設計図

## Phase 1で行わないこと

- EC2、Lambda、RDS、NAT Gateway、固定IPv4、ALB
- 独自ドメイン、Route 53、独自証明書、WAF
- サーバーへの個人情報・飛行記録保存
- アクセスログ収集（IPアドレス保管と料金を増やさないため初期は無効）

個人・運航情報は現在どおり利用者のブラウザ内だけに保存します。ブラウザや端末を変える前にJSONバックアップが必要です。

## 料金の考え方

S3とCloudFrontは保存量・リクエスト・通信量に応じた従量課金です。このアプリの配布量は小さく、個人利用なら通常は月数十円以内を目標にします。ただし利用回数、為替、AWS料金改定で変わるため保証値ではありません。

CloudFrontの有料定額プランは選ばず、従量制を使います。アカウント全体のAWS Budgetsで300円・700円・1,000円相当の通知を先に設定します。

| 条件 | 想定 | 主な課金要因 |
|---|---:|---|
| 通常時 | 月数円～数十円を目標 | S3保存・CloudFrontリクエスト/通信 |
| 上限時 | 月1,000円未満で監視 | 想定外の閲覧・通信増加 |
| 放置時 | 閲覧がなければ小額が残る | S3保存、CloudFrontへのアクセス |
