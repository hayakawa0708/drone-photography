# drone 停止・復旧手順

## 通常の公開停止

1. CloudFront管理画面で対象distributionを開く
2. 「無効化（Disable）」を選び、反映完了を待つ
3. CloudFront URLが配信されないことを確認する
4. S3のファイルは復旧用として残すか、削除するかを決める

CloudFrontはEC2のような起動時間課金ではありません。無効化してもS3保存料金は残ります。

## 更新失敗時の復旧

1. S3のバージョニング画面で`drone_checker.html`、`law_status.json`、`vendor/`の直前版を確認する
2. 対象を「現在の版」へ戻す
3. CloudFrontキャッシュの最大TTLは24時間、既定TTLは1時間なので、緊急でなければ反映を待つ
4. 緊急時だけCloudFront invalidationを実行する（当日の料金条件を確認）
5. CloudFront URLで地図、候補選択、1km警告、法令表示を再確認する

## 利用者データの復旧

AWSには個人・運航情報を保存しません。利用者データはブラウザのlocalStorageが正本です。

1. 端末・ブラウザ変更前に「全データをエクスポート（JSON）」を実行
2. 復旧先で「データをインポート（JSON）」を選ぶ
3. 件数、パイロット情報、飛行記録を画面で確認
4. 元端末のデータは確認が終わるまで削除しない

## 全削除

1. 必要な利用者JSONと公開ファイルを確認
2. CloudFront distributionをDisableする
3. CloudFormation Stackを削除する
4. S3は`DeletionPolicy: Retain`のため残る。bucket名と中身を再確認する
5. ユーザーの明示承認後、S3の全バージョンとbucketを削除する
6. Budgets/請求画面とリソース台帳を確認する
