# drone Phase 1 構築・更新手順

AWS操作はユーザー本人が行います。`01_作成前チェックリスト.md`が完了するまでStackを作りません。

## 1. Windowsで配布物を作る

作業場所: `C:\Users\haya0\Documents\drone`

```powershell
deploy\aws\scripts\01_配布フォルダ作成.bat
```

`.aws-build\drone-site\`へ、HTML、法令状態JSON、Leaflet、JSZip、ライセンスだけをコピーします。テスト、README、Git、`.claude`、個人データ、ログ、AWS設定は含めません。

## 2. CloudFormationを確認する

作業場所: AWS管理画面 → CloudFormation → 東京リージョン

1. 「スタックの作成」→「新しいリソースを使用」
2. `deploy/aws/cloudformation/static-site.yaml`をアップロード
3. Stack名を`drone-phase1`にする
4. 変更内容が台帳の6種類だけか確認する

**停止点:** 最後の「送信」を押すとAWSリソースが作られ、従量課金対象になります。ユーザーが明示的に開始すると決めるまで押しません。

## 3. 出力値を控える

Stackの「出力」から次を控えます。

- `SiteBucketName`
- `DistributionId`
- `SiteUrl`

## 4. S3へ配置する

作業場所: Windows

```powershell
deploy\aws\scripts\02_S3へ配置.bat
```

bucket名とdistribution IDを入力し、表示された送信先を確認して`DEPLOY`と入力します。既存オブジェクトは自動削除しません。

通常更新は1時間程度のキャッシュ反映を待ちます。緊急更新だけinvalidationを選択します。

## 5. 実機確認

`SiteUrl`をブラウザで開きます。

1. HTTPSになっている
2. プライバシー表示が読める
3. 「東京国際空港 羽田」では候補を選ぶまで判定が始まらない
4. `東京都大田区羽田空港3丁目3-2`を選ぶと1km簡易警告が出る
5. 地図、DID、天気、法令確認日が表示される
6. テスト用飛行記録を追加し、ExcelとJSONを保存できる
7. S3オブジェクトURLを直接開くとAccessDeniedになる

失敗時は`03_停止・復旧手順.md`へ進みます。
